# Merèl — Everlasting Botanicals

Premium e-commerce storefront for hyperrealistic artificial flowers, aimed at
the Dutch/EU quiet-luxury interior market. Front-end demonstration: all state
is client-side; checkout hands off to a hosted Shopify/Stripe page in
production (never built here).

> Flowers that look real, last forever, and never need tending.

## Stack

- **Vite + TypeScript + vanilla DOM** — no framework, component-per-file,
  portable to a Shopify theme later.
- **Three.js** — lazy-loaded 3D product viewer (PDP only; separate chunk).
- **GSAP + ScrollTrigger** — scroll choreography; plain CSS micro-interactions.
- No jQuery, no CSS frameworks, no UI kits. Hand-built design system.

## Commands

```bash
npm install
npm run dev        # dev server
npm run build      # typecheck + static build → dist/
npm run preview    # serve dist/
npm run make:glb   # regenerate public/assets/models/vase.glb (no deps)
npm run qa:e2e     # 53-check Playwright walkthrough against `npm run preview`
```

`dist/` is fully static. The router uses the History API, so the host needs a
SPA rewrite (all paths → `index.html`) — Netlify/Vercel/Cloudflare defaults
work; on nginx use `try_files $uri /index.html;`.

## Architecture

```
src/
  data/        products (8 SKUs, full EN+NL copy), looks, reviews, config
  i18n/        en.ts / nl.ts dictionaries (~180 keys), t()/tt()/tp()
  lib/         safe localStorage wrapper, event bus, nl-NL money, DOM utils
  state/       cart (3 line kinds, gift, wrap), prefs (recent, promo, lang)
  components/  chrome, cart drawer, modals, quick view, lightbox,
               placeholder SVG art system, lazy 3D viewer
  pages/       home, shop, product, looks, story, care
  motion/      GSAP ScrollTrigger choreography (reduced-motion aware)
  router.ts    History-API routes: / /shop /product/:id /looks /story /care
```

Design decisions worth knowing:

- **Ratings are computed, never invented.** Every number shown (hero strip,
  card stars, PDP distribution, the home pull-quote) derives from
  `data/reviews.ts` at render time. Honesty is a design principle: no fake
  urgency, no fake press logos.
- **Colour is a true variant.** The same product in two colours produces two
  cart lines (`key = p:<id>:<colour>`).
- **Free gift** (`GIFT = { threshold: 175, items: [...] }`) is derived state:
  dropping below €175 revokes it silently because `activeGift()` re-checks the
  paid-items subtotal on every render.
- **Placeholder art system** (`components/art.ts`): every product renders as
  an SVG scene whose petals fill from the `--tint` CSS variable, so colourways
  retint in place. Real photography drops in via `p.images[]` when available.
- **3D pipeline**: products with `model` set get a 3D-first media slot. The
  engine is a dynamic import (three.js chunk never loads outside a PDP), shows
  the 2D art as poster while loading, auto-rotates gently until first
  interaction, and falls back to the 2D gallery on any failure. The
  placeholder vase GLB (26 KiB, budget <5 MB) is generated by
  `scripts/make-vase-glb.mjs` — dependency-free lathe geometry → binary glTF.
- **Storage** goes through `lib/storage.ts` only: try/catch with an in-memory
  fallback, so private browsing degrades silently.

## QA checklist (verified by `npm run qa:e2e`)

- Language toggle re-renders everything, including open cart drawer and the
  delivery countdown (localized weekday names, `<html lang>` updated).
- Gift threshold edge cases: chooser appears at ≥€175, chosen gift collapses
  to a claim card, dropping below €175 revokes silently.
- Colour variants land as separate cart lines; swatches retint card/PDP media
  in place without navigating.
- Quick view (≥560px) opens without navigating; card click still navigates.
- Promo modal appears once ~4.2s after first visit, never again (persisted),
  skipped when subscribed.
- Recently-viewed persists (max 8), shows at ≥2 entries excluding the current
  product, remembers the selected colourway.
- `prefers-reduced-motion`: content resolves to final state instantly; 3D
  auto-rotate disabled.
- 320–1440px layouts: 2-up mobile grids, sticky safe-area add-to-cart bar,
  quick view hidden <560px, burger nav <860px.
- Keyboard: focus-visible sage outlines, overlays trap focus and close on
  Escape, focus returns to the opener.
